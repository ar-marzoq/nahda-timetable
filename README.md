# جدول الحصص والمناوبات — أكاديمية نهضة العالمية (بنين)

صفحة واحدة مستقلة (`index.html`) لا تحتاج خادماً ولا اتصالاً بقاعدة بيانات.

## المحتوى
- **الجدول الأسبوعي** — كل المعلمين × الحصص العشر، مع تمييز معلم أو إخفاء الباقين.
- **جداول الفصول** — ٩ فصول (٧ الواحة، ٧ دادان، ٨، ٩، ١٠، ١١، ١٢ A level، ١٢ Diploma، ١٣) بتوقيت كل فصل.
- **جدول معلم** — أسبوع المعلم كاملاً بحصصه ومناوباته وفراغه.
- **مناوبات الفسح** — B1 ‏١٠:٣٠–١١:٠٠ (٦ مشرفين) · B2 ‏١٢:٣٠–١:١٥ (٣) · B3 ‏١:١٥–٢:٠٠ (٦)، ود. ماهر مشرف ثابت في الجميع.
- **تغطية الغياب** — اختيار معلم غائب أو أكثر، فيُقترح المغطي حسب الأقل حصصاً في اليوم نفسه.

الصفحة ثنائية اللغة (عربي / English) وقابلة للطباعة.

## التحديث
كل البيانات مضمَّنة داخل `index.html` في ثلاثة متغيرات قرب بداية وسم `<script>`:
`DATA` (المعلمون وحصصهم) · `DUTY` (المناوبات) · `CLASSES` (جداول الفصول).

## تنبيه
الملف يحتوي أسماء المعلمين وجداول المدرسة كاملة. إن نُشر في مستودع عام صار متاحاً لأي شخص.
